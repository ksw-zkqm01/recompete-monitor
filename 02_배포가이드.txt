=======================================================
 STEP 1. GitHub 저장소 만들기 (10분, 한 번만)
=======================================================

이미 vibenexus 저장소를 쓰고 계시니 방법은 아실 겁니다.
"별도의 새 저장소"로 만듭니다. vibenexus 에 섞지 않습니다.

 1) github.com -> New repository
    이름 예: recompete-monitor
    Private 로 만들어도 됩니다 (Pages 는 Public 저장소가 무료.
    Private + Pages 는 유료 플랜 필요 -> 무료로 가려면 Public).
    * Public 이어도 .env 와 나라장터 DB 는 .gitignore 로
      제외되어 있어 인증키가 올라가지 않습니다.

 2) 이 폴더 전체를 저장소에 푸시:
      git init
      git add -A
      git commit -m "recompete monitor"
      git branch -M main
      git remote add origin https://github.com/<아이디>/recompete-monitor.git
      git push -u origin main


=======================================================
 STEP 2. 자동 갱신 켜기 (5분, 한 번만)
=======================================================

 1) 저장소 -> Settings -> Secrets and variables -> Actions
    -> New repository secret
      이름: DATA_GO_KR_KEY
      값:  공공데이터포털 Decoding 인증키
    (이걸 넣어야 한국 데이터도 매일 수집됩니다.
     안 넣으면 미국 데이터만 갱신됩니다.)

 2) 저장소 -> Settings -> Pages
      Source: Deploy from a branch
      Branch: main  /  폴더: /docs  -> Save

 3) 저장소 -> Actions 탭 -> daily-update -> Run workflow
    (첫 실행을 수동으로 한 번 눌러서 확인)

 끝. 주소는  https://<아이디>.github.io/recompete-monitor/
 이후 매일 06:00 KST 에 자동 실행됩니다.


=======================================================
 STEP 3. (선택) Firebase Hosting 으로도 배포
=======================================================

GitHub Pages 만으로 충분합니다. Firebase 를 쓰는 이유는
커스텀 도메인 연결이 더 편하거나, 이미 Firebase 프로젝트가
있을 때입니다. 같은 docs/ 폴더를 그대로 배포합니다.

 1) console.firebase.google.com -> 프로젝트 추가 (Spark 무료)
 2) 프로젝트 설정 -> 서비스 계정 -> 새 비공개 키 생성 -> JSON 다운로드
 3) GitHub 저장소 Secrets 에 추가:
      FIREBASE_SERVICE_ACCOUNT = (JSON 파일 내용 전체 붙여넣기)
      FIREBASE_PROJECT_ID      = (프로젝트 ID)
 4) .github/workflows/update.yml 맨 아래
    "Deploy to Firebase Hosting" 블록의 주석(#)을 지우고 커밋

 * Firestore 같은 DB 는 지금 단계에선 불필요합니다.
   이 사이트는 읽기 전용 공개 데이터라 매일 갱신되는
   정적 JSON 이 곧 DB 역할을 합니다. 나중에 로그인/구독
   기능이 붙을 때 Firestore 를 도입하면 됩니다.
