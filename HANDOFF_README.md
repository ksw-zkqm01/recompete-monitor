## Architecture

```
                 ┌──────────────── core (country-agnostic) ───────────────┐
  US: DHS APFS ─▶│ snapshot ─▶ field diff ─▶ severity rules ─▶ action brief │─▶ email / md
  KR: 나라장터   ─▶│                                                        │
                 └────────────────────────────────────────────────────────┘
```

- `core/db.py` — `snapshot`, `change`, `brief_log` tables. Country-agnostic.
- `core/diff.py` — compares the two most recent snapshots per entity. Emits NEW / CHANGED / GONE.
- `core/rules.py` — **all customer-facing sentences live here.** Severity, "why this matters",
  and the recommended-action checklist are pre-written templates per field.
  No sentence and no number is generated by a language model.
- `core/brief.py` — renders the brief. English for `us`, Korean for `kr`.
- `sources/us_dhs.py` — wraps the previous prototype (`sources/_us_proto.py`) unchanged.
- `sources/kr_g2b.py` — reads the already-collected 나라장터 DB (`data/radar.sqlite3`).

## Live-source correction — 2026-08-30

The previous session's APFS ingestion could never have returned a record. Two defects, both fixed:

1. **`https://apfs-cloud.dhs.gov/forecast/?action=csv` no longer serves CSV.**
   It returns `200 text/html` (a 32 KB HTML page). `csv.DictReader` produced 679 junk rows
   with a single `None` header. The live data is on the JSON API:
   **`https://apfs-cloud.dhs.gov/api/forecast/`** — 844 records, one JSON array.
2. **`contract_status` is a code (`NEW` / `REC` / `NLR`), not the word "Follow-on".**
   The old filter `"follow" in contract_status` matched nothing.
   Follow-on is carried by **`competitive`**:
   `Follow-on to Existing Contract` (276) · `New Requirement, No Contract` (561) ·
   `No Longer Required` (7).

Other field facts confirmed against live data:
`naics` is `"541512 - Computer Systems Design Services"` (split on `" - "`);
`dollar_range` is an object with `display_name`; dates are `MM/DD/YYYY`;
`previous_published_date` and `last_updated_date` exist on the record;
`apfs_number` sometimes carries a leading `*` (meaning not confirmed — kept verbatim).

`sources/us_dhs.py` now calls the JSON API directly. `_us_proto.py` is untouched and still
supplies scoring, USAspending and SAM.
